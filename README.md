# FIFA 19 MOD 快速加载器（中文）

用中文界面管理和启动 FIFA 19 的 Frosty MOD。

- **不需要注入器**：自带代理 DLL，游戏启动时会自动加载 MOD 所需的 DLL，不用再开 Extreme Injector。
- **内置 FMM**：包里已经带了 Frosty Mod Manager 1.0.6.2（`FMM\` 文件夹），不用另外下载安装，也不用指定目录。
- **MOD 没变就秒启**：直接带着已生成的 MOD 数据启动游戏，不运行 FMM。
- **MOD 变了自动生成**：在后台调用内置 FMM 重新生成数据，完成后自动启动游戏。

内置 FMM 只负责在后台生成数据，所有操作都在本工具里完成。

> **关于本仓库**：这里只放源码和程序本体（`source\`、`proxy\`、`FIFA19QuickLoader.exe`）。内置的 Frosty Mod Manager（`FMM\`，开源项目 Frosty Toolsuite，GPLv3）和 VC++ 运行库安装包没有随仓库分发——它们体积大、且应当由使用者自己获取。按 [八、从源码编译](#八从源码编译) 编译出程序后，把 FMM 的 `FMM\` 文件夹放到工具根目录即可使用；缺少 `FMM\` 时，所有"内置 FMM"相关功能不可用。下文按完整分享包的用法描述。

## 一、适用范围

| 项目 | 要求 |
|---|---|
| 游戏 | FIFA 19 PC 版 |
| MOD 所需 DLL | 5 个游戏自带 DLL（`sysdll_Win64_retail.dll`、`CardsDLL_Win64_retail.dll`、`FootballCompEng_Win64_retail.dll`、`powdll_Win64_retail.dll`、`dbdata.dll`）由游戏提供；`CryptBase.dll` 随工具提供，安装代理时自动复制到游戏目录 |
| 系统 | Windows 10/11 x64，自带 .NET Framework 4.7.2 以上（Win10 1803 以后都有，不用另装）；FMM 还需要 VC++ 2015/2017 运行库，缺少时安装包在 `FMM\Prereqs\` 里 |

> 本工具只修改 FMM 的配置文件（`%LOCALAPPDATA%\Frosty\manager_config.json`），并在游戏目录放一个代理 DLL，不修改 `FIFA19.exe`。

## 二、首次使用

1. **解压前先解除锁定**：右键下载的 zip → **属性** → 勾选底部的 **解除锁定** → 确定，然后再解压。
   - 不这样做，Windows 会把解压出的每个文件都标记为"来自互联网"，双击时就会弹"打开文件 - 安全警告"或"Windows 已保护你的电脑"。
   - 如果忘了这一步：弹窗时点"运行"或"更多信息 → 仍要运行"即可。工具启动后会自动解除自身所有文件的锁定，之后就不会再弹，内置 FMM 也能正常加载它的组件。
   - 不要用 bat 脚本来"绕过"这个警告。bat 文件下载后同样带有标记，照样会弹警告。
2. 把整个文件夹放到任意位置（路径最好不含特殊符号），双击 `FIFA19QuickLoader.exe`。
3. **先设置游戏目录**：工具会先从注册表和常见游戏库位置查找 `FIFA19.exe`。找到后会显示路径让你确认；没找到或路径不对时，会打开选择窗口，请选中游戏目录里的 `FIFA19.exe`。设置后会自动记住，以后可以点 **更改游戏目录…** 修改。
4. **首次安装代理**：如果代理未安装，工具会询问是否现在安装。点“是”立即安装；点“否”后不再自动询问，但仍可随时点 **安装免注入代理**。
   - 工具会把游戏目录里原来的 `amd_ags_x64.dll` 改名为 `amd_ags_x64_orig.dll`，再把代理放进去。
   - 如果游戏目录缺少 `CryptBase.dll`，工具会从内置 FMM 自动复制；已有文件不会覆盖。还原时仅删除工具安装且内容未被修改的那份。
   - 顶部会检查 5 个游戏自带 DLL 和 `CryptBase.dll`。缺少游戏自带 DLL 时，请通过 EA App/Origin 修复游戏文件；缺少 `CryptBase.dll` 时，点击提示旁的补装按钮。
   - 游戏装在 `C:\Program Files` 这类目录时，需要右键工具，选"以管理员身份运行"。
5. 把 MOD 文件拖进窗口导入。
6. 第一次启动时，内置 FMM 要先给游戏建缓存，再生成 MOD 数据，可能需要 5～15 分钟，期间会看到 FMM 的进度窗口，属于正常现象。以后只要 MOD 没变，都是秒启。

## 三、界面说明

```
┌ 游戏目录 [更改游戏目录…] [游戏设置（1920x1080 无边框窗口）…] / 内置 FMM 版本 / 免注入代理状态 ┐
├ MOD 库（左）─────────────────┬ 启用方案（右）─────────────────┤
│ 搜索、导入、加入方案、删除文件 │ 方案下拉框 + 新建/复制/删除      │
│ 支持把文件直接拖进窗口         │ 勾选 = 启用；置顶/上移/下移/置底 │
├ MOD 详情 ─────────────────────────────────────────────────────┤
├ 状态提示（⚡秒启 / 需要生成）  [刷新] [保存] [重新生成并启动] [▶ 启动游戏] ┤
```

- **MOD 库**：即 `FMM\Mods\FIFA19` 文件夹。
- **方案**：就是 FMM 里的 Pack，可以给不同玩法建不同方案。
- **顺序**：从上往下依次应用，两个 MOD 修改了同一内容时，**下面的覆盖上面的**。
- **状态列**：显示"正常""文件缺失""非 FIFA19 MOD"等。文件缺失的 MOD，FMM 生成时会直接跳过。

## 四、日常使用

### 导入 MOD
- 点 **导入 MOD…**，或者把文件拖进窗口。
- 支持 `.fbmod`、`.fbcollection` 和 `.zip`。zip 会自动解压，并去掉多余的文件夹层级。
- 大型 MOD 附带的 `xxx_01.archive` 等文件会一起复制，**不要漏掉**。
- `.rar` 和 `.7z` 请先自己解压，再导入里面的 `.fbmod`。
- 其他游戏的 MOD 会被拒绝导入。

### 调整方案
1. 选中左侧的 MOD，点 **加入方案 →**。
2. 在右侧勾选或取消勾选，用按钮调整顺序。
3. 点 **保存**。直接点启动游戏也会先自动保存。

### 启动游戏
- 底部提示 **⚡ MOD 数据已是最新**：点 **▶ 启动游戏** 就是秒启，不会打开 FMM。
- 底部提示 **需要生成**：点 **▶ 启动游戏** 后，工具会在后台运行 FMM，生成完成后游戏自动启动，FMM 自动关闭。
- **重新生成并启动**：用于游戏更新后，或者怀疑数据损坏时，强制重新生成一次。

以后也可以不开本工具，直接双击 `FIFA19.exe` 启动：代理照样会加载 DLL。但这样启动的游戏**不带 MOD 数据**，因为只有带上 `-dataPath` 参数才会加载 MOD。要玩 MOD，请从本工具启动。

### 游戏设置（分辨率、画质、语言等）
- 点顶部的 **游戏设置（…）** 按钮，按钮上显示当前分辨率和显示模式。
- 弹窗里就是游戏自带 `FIFASetup\fifaconfig.exe` 的全部选项，分三组：
  - **显示**：分辨率（可从显示器支持的列表选，也可直接输入，如 `2560x1440`）、显示模式（全屏 / 无边框窗口 / 窗口）、DirectX 版本（自动 / 11 / 12）。
  - **画质与帧率**：画面质量（自动 / 低 / 中 / 高 / 极高）、MSAA 抗锯齿（自动 / 关闭 / 2x / 4x）、帧率限制（不限 / 60 帧 / 30 帧）。
  - **音频、手柄与语言**：声道（立体声 / 5.1 / 7.1）、语音聊天、手柄按键图标（字母 / 数字）、游戏语言。
- 修改的是 `文档\FIFA 19\fifasetup.ini`，**只写入你改动过的项目**，其他内容保持原样。首次保存会备份为 `fifasetup.ini.quickloader.bak`。
- 改完后重新启动游戏才生效。全屏选了显示器不支持的分辨率可能黑屏；DX12 闪退或黑屏时请改回 DX11。
## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示"FMM 正在运行" | FMM 关闭时会覆盖配置文件，所以工具拒绝在 FMM 运行时保存。等内置 FMM 生成完自动退出，或者关掉你另外打开的 FMM。 |
| 弹"打开文件 - 安全警告" / "Windows 已保护你的电脑" | 文件带有"来自互联网"标记。见"首次使用"第 1 步。 |
| FMM 生成时报错，提到 loadFromRemoteSources、0x80131515 或无法加载 Newtonsoft.Json | 是下载标记导致的。内置 FMM 已带 `FrostyModManager.exe.config`（开启 loadFromRemoteSources）来规避，请确认这个文件没有丢；仍然报错时，先给 zip 解除锁定，再重新解压。 |
| 换了游戏目录（或复制过 ModData）后，代理显示已安装，但游戏启动几秒就退出 | `ModData\方案名` 里缺少指向游戏原始数据的链接（Data、Update 和 patch 下的 .cas）。FMM 只在第一次生成时创建这些链接，之后不会修复。本工具启动时会自动检测，提示后删除该方案数据，交给 FMM 重新生成；期间 FMM 会请求一次管理员权限（UAC），请点“是”。 |
| 代理显示“状态异常”，或显示已安装但 MOD DLL 没被加载（游戏目录里的 `fifa19_proxy.log` 没有更新） | 点代理状态右侧的 **强制重装代理**。它会从原版重新生成备份、重新写入代理、修复 CryptBase.dll；被覆盖的未知文件改名保留为 `*.quickloader-时间.bak`。若原版 `amd_ags_x64.dll` 和备份都找不到，会拒绝操作，请先修复游戏文件。 |
| 提示"配置文件已被外部修改" | 工具打开后，其他程序（比如另外打开的 FMM）改了配置。点 **刷新** 重新读取即可。 |
| 提示"游戏已在运行" | 先退出游戏，或在任务管理器里结束 `FIFA19.exe`。 |
| 安装或还原代理失败、拒绝访问 | 以管理员身份运行工具；也可能是杀毒软件拦截，请把游戏目录加入白名单。 |
| 进游戏后 MOD 没生效 | 确认是从本工具启动的；点一次"重新生成并启动"；检查方案里的 MOD 是否已勾选、状态是否"正常"。 |
| 游戏更新以后启动出错 | 先点"重新生成并启动"。如果游戏更新替换了 `amd_ags_x64.dll`，工具会显示代理"未安装"或"异常"，重新安装一次即可。 |
| 想恢复 FMM 原来的配置 | 工具第一次保存前，会把配置备份为 `%LOCALAPPDATA%\Frosty\manager_config.json.quickloader.bak`。改名覆盖回 `manager_config.json` 即可恢复。 |
| 程序崩溃 | 查看工具目录下的 `error.log`。 |

## 六、完全还原

1. 在工具里点 **还原原版 DLL**。这一步会删除代理，并把 `amd_ags_x64_orig.dll` 改回 `amd_ags_x64.dll`；若 `CryptBase.dll` 是工具安装且未被修改，也会一并移除。
2. 删除本工具文件夹。

游戏目录里生成的 `ModData\` 可以手动删除。`%LOCALAPPDATA%\Frosty\` 下是 FMM 的配置，不再使用 FMM 时也可以删除。

## 七、工作原理（简述）

1. **免注入**：游戏启动时会加载同目录下的 `amd_ags_x64.dll`。代理 DLL 把全部 AMD 函数原样转发给 `amd_ags_x64_orig.dll`，同时在后台线程依次 `LoadLibrary` 那 6 个 MOD DLL，效果和注入器一样，只是时机更早，也不用手动操作。
2. **秒启判定**：FMM 生成数据后，会在 `游戏目录\ModData\<方案>\patch\mods.json` 记录当时的 MOD 列表。工具把它和当前启用的 MOD（名称、版本、分类、文件名、顺序）逐项比较，同时检查 MOD 文件和游戏 `layout.toc` 的修改时间。全部一致时，就直接运行：
   `FIFA19.exe -dataPath "游戏目录\ModData\<方案>"`
3. **自动生成**：不一致时，运行内置的 `FMM\FrostyModManager.exe -launch <方案>`。这是 FMM 自带的命令行参数，会生成数据、启动游戏，然后自动退出。

## 八、从源码编译

```
source\
├─ QuickLoader\   C# WinForms 工具（.NET Framework 4.7.2）
└─ proxy\         代理 DLL（C，MSVC x64）
```

- 工具：需要 .NET SDK（6 或以上，能编 net472 即可）
  ```
  cd source\QuickLoader
  dotnet build -c Release
  ```
  生成的 `bin\Release\net472\FIFA19QuickLoader.exe` 复制到包的根目录即可。
- 代理：需要 Visual Studio 2019/2022 的 C++ 生成工具。在 `source\proxy` 下运行 `Build.cmd`，会输出到 `proxy\amd_ags_x64.dll`。然后运行 `Update-Manifest.ps1` 更新 `proxy\proxy-manifest.json` 里的哈希。

## 九、分享须知

- 分享包内容：`FIFA19QuickLoader.exe`、`FIFA19QuickLoader.exe.config`、`FMM\`、`proxy\`、`README.md`，以及可选的 `source\`。
- **不要放进去**：`FMM\Caches\`（约 200 MB，要按各自电脑上的游戏生成）、`FMM\Mods\` 里你自己的 MOD、`error.log`。
- 内置的 FMM 是开源项目 Frosty Toolsuite（GPLv3），这里只保留了 FIFA 19 需要的文件（`Profiles` 只留了 `FIFA19SDK.dll`）。
- 不要附带游戏文件或 MOD DLL，对方需要自己准备。
- 仅供单机离线游玩使用。
